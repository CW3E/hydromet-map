# User Guide

This section is reserved for regular app users who do not modify the codebase.

The current repository documentation is still focused on developers:

- app developers working on the framework
- project developers adding projects, layers, popups, plots, tools, and status panels

Future user-guide topics may include:

- switching basemaps, terrain, and projection
- turning layers on and off
- changing dates and products
- using bookmarks and QR codes
- opening popups and downloading data
- using context-menu tools and temporary map overlays
- interpreting status panels

For now, see the main developer documentation index at [docs/README.md](../README.md).
