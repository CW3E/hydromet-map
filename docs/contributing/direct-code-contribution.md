# Direct Code Contributions

Direct repository work is optional. Domain contributors can use the proposal
forms and preview-review path instead.

If you want to edit code:

1. Create a short-lived branch for one focused change.
2. Follow the relevant [developer how-to guide](../how-to/README.md).
3. Reuse existing project, layer, popup, and control patterns.
4. Preserve stable IDs, URLs, bookmark parameters, and unrelated projects.
5. Run `npm run lint` and `npm run build` when feasible.
6. Open a pull request and complete the scientific portion of its template.

GitHub Desktop can clone the repository, create a branch, show changed files,
commit, push, and open a pull request without command-line Git.

Ask an AI coding agent to use the repository's
`hydromet-map-config-workflow` skill. The agent can inspect nearby examples,
make coordinated edits, run validation, and prepare a review summary.
