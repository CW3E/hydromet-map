# Contributing for Domain Experts

Hydromet Map is built with meteorologists, hydrologists, data producers, and
other environmental scientists. Your knowledge of the data and how they should
be communicated is the essential contribution.

You do not need to:

- write JavaScript
- use command-line Git
- understand continuous integration
- know the internal map architecture

Choose the path that fits what you want to do:

- [Share your data or visualization idea](./share-your-data.md)
- [Review a map preview](./review-a-map-preview.md)
- [Contribute code directly](./direct-code-contribution.md)

An AI agent or software maintainer can translate a scientific request into the
application's project, layer, legend, popup, and bookmark configuration. It is
fine to start with incomplete information and answer follow-up questions later.

## A few useful terms

| What you may call it | What the application calls it |
| --- | --- |
| A dataset displayed on the map | Layer |
| A map assembled for a region or purpose | Project |
| Variable, date, product, or lead-time controls | Layer family |
| A color scale with values and units | Palette and legend |
| A shareable map setup | Bookmark |
